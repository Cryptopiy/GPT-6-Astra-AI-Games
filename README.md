### GPT 6 Astra — 5 браузерных игр, сделанных ИИ

Проекты из ролика-теста **GPT 6 Astra**: маленький открытый город Portside (первая версия), краш-лаборатория IMPACT, два симулятора цунами (Tideline и SURGE) и 2D-выживание EMBERWILD. React + Three.js + Vite, всё работает в браузере.
