# Tideline — Tsunami Disaster Simulator

> **Как запустить готовую сборку / How to run the ready-made build:** см. / see [HOW_TO_PLAY.md](../../HOW_TO_PLAY.md) в корне репозитория / in the repository root. Если ниже упоминаются другие файлы запуска — их в этом репозитории нет / if other launch files are mentioned below, they are not part of this repository.

Локальный интерактивный 3D-симулятор цунами на TypeScript, React, Vite и Three.js. Процедурный город North Haven занимает 288 × 240 м: берег, низины, холм высотой около 29 м, дороги, 27 неподвижных зданий и 16 машин. Исходная игра Portside в родительской папке сохранена.

## Запуск

Нужен Node.js 22.12+ и браузер с WebGL 2.

```powershell
cd <путь-к-папке-проекта>
npm install
npm run dev
```

Открыть **http://127.0.0.1:5174/**. Если PowerShell блокирует `npm.ps1`, использовать `npm.cmd install` и `npm.cmd run dev`. Сервер слушает только локальный интерфейс. Порт указан явно; занятый порт приводит к понятной ошибке, а не запуску по другому адресу.

```powershell
npm test
npm run build
npm run preview
```

Предпросмотр production-сборки: http://127.0.0.1:4174/. `dist/` содержит самостоятельную статическую сборку. Во время работы приложение не использует внешние API, карты, шрифты, изображения, аккаунты или backend. Установка зависимостей на новом компьютере обычно требует доступа к npm.

## Управление

| Управление | Действие |
|---|---|
| Wave height, 1–20 m | Высота входящего импульса; меняется перед следующим запуском |
| Small / Major / Extreme | Пресеты 3, 10 и 20 м |
| START TSUNAMI | Новый прогон из спокойного состояния |
| PAUSE / RESUME, пробел | Остановка / продолжение физики |
| RESET, R | Сброс воды, потоков, машин, таймера, счётчиков и графика |
| 1× / 2× / 4× | Скорость модельного времени |
| Перетаскивание | Вращение перспективной камеры |
| Колесо / жест масштабирования | Приближение и отдаление |
| Правая кнопка + перетаскивание | Перемещение камеры |
| Overview / Coast view | Два положения перспективной камеры |
| Elevation | Цветовые диапазоны высоты рельефа |
| About the model | Описание модели; Escape закрывает окно |

Один прогон длится 150 модельных секунд, примерно 38 секунд при 4× на достаточно быстром компьютере. При скрытой вкладке модельное время не продвигается. Для сравнения выполнить прогон 1 м, затем 20 м: менять высоту и запускать снова можно без обновления страницы.

## Распространение воды

- Сетка **96 × 80**, размер ячейки **3 м**. `Float64Array` хранит высоту грунта, глубину, расход через грани и компоненты скорости.
- Каждая вершина основного 3D-рельефа соответствует значению массива высот. Постоянное море изначально заполняется до отметки 0 м.
- Единственная внешняя граница подачи/отвода воды — край со стороны моря. На ней задан импульс `H × sin²(πt/78)` при `0 < t < 78 с`, затем уровень возвращается к нулю. Внутренние ячейки никогда не заполняются по готовой маске.
- Для каждой пары соседей рассчитывается разность уровней `η = грунт + глубина`. Расход обновляется с локальной инерцией, ускорением тяжести и полунеявным сопротивлением Маннинга. Взвешивание предыдущих расходов соседних граней подавляет колебания масштаба сетки.
- Все исходящие потоки одной ячейки ограничиваются доступным объёмом. Один и тот же объём вычитается у донора и добавляется получателю. Отдельный баланс учитывает только обмен с морской границей.
- Вода пересекает гребень только при достаточном уровне; низины собирают воду, дороги углублены в рельеф, здания блокируют грани. Северная, южная и дальняя сухопутная границы замкнуты.
- Фиксированный шаг **1/30 с** отделён от React. Динамический буфер поверхности обновляется до 15 раз в реальную секунду, камера и машины — каждый кадр. Нет React-компонента на каждую ячейку.

Это упрощённая локально-инерционная схема, вдохновлённая работой [Almeida et al., 2012](https://agupubs.onlinelibrary.wiley.com/doi/10.1029/2011WR011570). Это не полная система уравнений мелкой воды и не инструмент прогнозирования опасности.

## Машины и столкновения

Сила сопротивления воды зависит от относительной скорости, смоченной площади, коэффициента сопротивления, плотности воды и массы машины. При увеличении глубины плавучесть уменьшает сцепление с грунтом. Полунеявное интегрирование не позволяет машине бесконтрольно ускоряться на фронте воды. Полностью плавающая машина приближается к местной скорости течения; на мелководье остаётся почти неподвижной.

Машины всплывают, поворачиваются по течению и наклоняются от поперечного потока. Перемещение разбивается на короткие шаги с проверкой круглого контура машины против прямоугольников зданий. Раздельное разрешение движения по двум осям позволяет скользить вдоль стены. Между машинами действует простое раздвигание, здания остаются неподвижными. Движение не задаётся случайными траекториями и не зависит напрямую от положения слайдера.

## Статистика

- **Flooded Area**: доля первоначальных сухопутных ячеек с глубиной строго больше **0,15 м**. Постоянный океан исключён. Знаменатель включает ячейки под зданиями; их внутреннее затопление не моделируется.
- **Max. land depth**: текущая максимальная глубина на суше, без моря.
- **Flooded buildings**: число зданий, у которых вода в мокрых контрольных точках рядом с фасадами выше основания более чем на 0,15 м. Сухой высокий грунт водой не считается.
- **Displaced vehicles**: число машин, которые хотя бы раз ушли дальше 2 м от начальной позиции.
- **Peak** и график: максимальная и текущая доля затопленной суши за этот прогон. Встроенный максимум обновляется каждые 0,2 модельной секунды и при чтении статистики; React обновляется примерно восемь раз в секунду.

## Проверенные результаты

Полные детерминированные прогоны по 150 с, фиксированный шаг 1/30 с:

| Высота волны | Пиковая затопленная суша | Машины, смещённые >2 м | Затопленная суша в конце |
|---|---:|---:|---:|
| 1 м | 10,26% | 0 / 16 | 1,15% |
| 10 м | 62,75% | 15 / 16 | 9,36% |
| 20 м | 90,89% | 16 / 16 | 16,96% |

Для 20 м низкий контрольный участок затапливается на 20-й секунде, более высокий вдоль той же дороги — на 43-й. Для 1 м второй участок остаётся сухим. Числа относятся только к этой процедурной карте и упрощённой модели.

`npm test`: **13 тестов успешно**, в том числе отсутствие отрицательных/нечисловых значений, баланс объёма, спокойное равновесие, причинная достижимость соседей, непроницаемая стена, удержание воды в низине, минимум/максимум, статистика, пауза, полный сброс, точное воспроизведение повторных запусков, масса/плавучесть и столкновение с тонким препятствием.

`npm run build`: строгая проверка TypeScript и production-сборка прошли. В браузере проверены последовательные запуски 20 м и 1 м, управление высотой, пауза/продолжение, завершение, график повторного прогона, камера и счётчики. Во время большой волны при 4× измерено около **60 FPS**, **116 draw calls**, **115 геометрий**, **3 текстуры** на использованном компьютере. Это измерение, а не гарантия для любого устройства. Подробности: [evidence/verification.md](evidence/verification.md), [лог тестов](evidence/unit-tests.txt).

## Упрощения

Это модель на сетке 3 м, поэтому кромка воды может иметь ступенчатый вид. Вертикальный масштаб рельефа и поверхности воды визуально увеличен в 1,35 раза; вычисления и числовые подписи остаются в физических метрах. Декоративные деревья и причалы не участвуют в гидродинамике. Здания непробиваемы, не разрушаются и не моделируют проникновение воды внутрь. Контакт машин приближён кругами, без полной динамики подвески и жёстких тел. Пешеходов нет. Волна — длинный граничный импульс, без обрушивающегося гребня, землетрясения, эрозии или расчёта повреждений.

В браузерах с WebMCP доступны `read_tsunami_simulation` и `control_tsunami_simulation`; они используют то же состояние и действия, что кнопки. На браузерах без этого API интерфейс работает самостоятельно. В dev-режиме DOM содержит диагностические показатели для проверки производительности; production-сборка их не записывает. Ничего не отправляется на внешние серверы.
