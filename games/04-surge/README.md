# SURGE — Tsunami Laboratory: запуск

> **Как запустить готовую сборку / How to run the ready-made build:** см. / see [HOW_TO_PLAY.md](../../HOW_TO_PLAY.md) в корне репозитория / in the repository root. Если ниже упоминаются другие файлы запуска — их в этом репозитории нет / if other launch files are mentioned below, they are not part of this repository.

Эта папка — самостоятельная копия результата. Требуется Node.js 22.12+ и браузер с WebGL 2, клавиатура и мышь. Интернет нужен для первой установки зависимостей. Аккаунт и API-ключ для приложения не нужны.

1. Полностью распакуйте общий архив.
2. Откройте PowerShell в этой папке.
3. Выполните:

```powershell
npm.cmd ci
npm.cmd run dev -- --port 5185 --strictPort
```

Откройте http://127.0.0.1:5185/ . Сервер останавливается Ctrl+C. Если порт занят, выберите другой после `--port`. Повторная установка нужна только после изменения зависимостей.

## Проверки и production-версия

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run preview -- --port 5185 --strictPort
```

Архив включает готовый `dist` и исходный код. Для готового `dist` достаточно HTTP-сервера: из этой папки `python -m http.server 5185 --bind 127.0.0.1 --directory dist`, затем откройте тот же адрес. Двойной щелчок по HTML не заменяет HTTP-сервер.

## Управление

Выберите высоту волны и нажмите START TSUNAMI. Доступны PAUSE/RESUME, RESET, скорости 1×/2×/4×. Мышь вращает камеру, колесо меняет масштаб. Это учебная модель, а не прогноз реальной катастрофы.

## Состав и происхождение

`src` — исходники, `tests` — тесты приложения, `public` — локальные ресурсы, `verification` — новый протокол проверки копии. Первоначальное описание сохранено в `docs/ORIGINAL_README.md`; упоминания общей папки и других приложений в нём исторические.

При упаковке изменены только точка входа и конфигурация сборки, чтобы приложение открывалось по `/` и не зависело от соседних результатов. Игровая логика сохранена. Зависимости и lock взяты из зафиксированного общего проекта b774e63, до добавления Phaser для Emberwild. Исходный рабочий проект не изменялся.
